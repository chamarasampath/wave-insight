Wave Insight Technology

Wave Insight combines handheld waveform comparison in the Wi-100 with live browser-based AC monitoring and analysis in the Wi-Fi100.

Wi-100 Handheld Analysis

🌊 Waveform Visualization

Wave Insight displays AC waveform patterns in real time, allowing users to observe waveform shape and behavior from different power sources.

📈 Waveform Comparison

Wave Insight allows users to compare waveform patterns visually with a stored reference waveform, helping identify changes in waveform shape.

🔔 Adjustable Buzzer Alert

Wave Insight includes a configurable buzzer alert function. Users can adjust the beep timing to suit their waveform observation and comparison requirements.

🎚 Sensitivity Control

Adjustable sensitivity allows users to select the required response level when observing waveform differences.

Wi-Fi100 Connected Monitoring

Wi-Fi100 combines the device's live electrical measurements with a browser dashboard, so readings and power-quality details can be viewed locally or remotely.

Live AC Measurements

View RMS voltage, peak voltage, and frequency readings while the analyzer monitors the AC source.

Waveform and Harmonics

Follow the live waveform, review total harmonic distortion (THD), and inspect individual harmonic levels up to H50.

Local Browser Access

Open the device's web page from a phone or computer on its Wi-Fi connection. Local monitoring does not require internet access.

Optional Remote Viewing

When internet access is available and remote viewing has been paired and enabled, view the device dashboard from outside the local network.

History and Charts

Use the dashboard's charts and measurement history to follow changes over time.

Alerts and Device Settings

Configure measurement alert limits, choose where live data is viewed, and manage device options from the browser. Email and Telegram notifications require internet access.

Browser-Based Updates

Use the device's firmware page to install its signed update package and view the update progress.
